Ask the concierge who you should meet

One message runs a full agent turn. The model searches this event's attendees by meaning, scores the promising ones, drafts intro messages for the best, then answers. That is up to six model calls, so expect 30–60 seconds.

The panel on the right shows every call it made: what it said, which tools it chose, the exact arguments, and what came back.

Conversations are stored per attendee on the server, so a follow-up still works after a reload. This page only shows the turns sent from this tab.
